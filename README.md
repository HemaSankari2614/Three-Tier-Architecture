# 🏗️ Three-Tier Architecture in C# 🚀

🌟 A C# application developed using the Three-Tier Architecture to separate presentation, business logic, and data access layers. This project demonstrates structured application development, maintainability, and separation of concerns.

## 🛠️ Technologies Used

- 💻 C#
- 🗄️ SQL Server
- 🔗 ADO.NET
- 🪟 Windows Forms / WPF
- 🏛️ Three-Tier Architecture

## 📚 Architecture Layers

### 🎨 1. Presentation Layer
- Handles the user interface.
- Accepts user input.
- Displays application results.

### 🧠 2. Business Logic Layer (BLL)
- Contains business rules and logic.
- Validates user input.
- Connects the presentation layer with the data access layer.

### 🗃️ 3. Data Access Layer (DAL)
- Handles database operations.
- Executes SQL queries.
- Performs CRUD operations using ADO.NET.

## ✨ Concepts Practiced

- Separation of Concerns
- Layered Architecture
- CRUD Operations
- Database Connectivity
- Code Reusability
- Maintainability

## 🎯 Learning Objectives

- Understand Three-Tier Architecture.
- Separate UI, business logic, and database operations.
- Improve application structure and maintainability.
- Practice database interaction using C# and SQL Server.

## 💡 Purpose

This project serves as a learning reference for implementing Three-Tier Architecture in C# applications.
